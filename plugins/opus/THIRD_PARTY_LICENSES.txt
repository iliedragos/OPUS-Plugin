Compatibility patch applied by this plugin distribution
-------------------------------------------------------
The previously vendored minified browser bundle was affected by the upstream
property-mangling defect documented for wasm-audio-decoders issue #129. The
bundle in this distribution preserves the same embedded decoder payload but
restores the documented public constructor option keys `channels`,
`streamCount`, `coupledStreamCount`, `channelMappingTable`, `preSkip`, and
`forceStereo`, plus the documented decoded-result field `errors`. Runtime
regression tests verify mono configuration and non-zero preSkip are consumed.
This file is therefore intentionally described as a compatibility-patched
vendored build; it is not represented as an untouched upstream 0.7.12 file.
